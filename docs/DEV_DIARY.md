# 📖 Дневник разработки Randomattic (Dev Diary & Roadmap)

> **Концепт проекта:** Randomattic (*Random + Attic*) — Чердак случайностей и диковинок. Интерактивный AppBoard и набор инструментов для ведущих и игроков в настольные ролевые игры (в первую очередь D&D 5e).
> **Хостинг:** GitHub Pages (Zero-dependency, Vanilla ES6, CSS Custom Properties).

---

## 🧭 Архитектурные ориентиры и правила проекта

1. **Без тяжелых фреймворков на старте:**
   - Чистый нативный JavaScript (ES6 модули `import` / `export`).
   - Чистый семантический HTML5 и CSS3.
   - Никаких обязательных сборок (`npm run build`) — любой коммит в ветку `main` сразу доступен на GitHub Pages.

2. **Модульность генераторов:**
   - Все генераторы регистрируются в `js/data/generators-registry.js`.
   - Общая математика, кубики, монеты и случайности выносятся в `js/utils/`.
   - Любой новый генератор импортирует утилиты через единый фасад:
     ```javascript
     import { dice, currency, random } from '../utils/index.js';
     ```

3. **Дизайн-система (Двойная эстетика):**
   - **Тёмная тема (Midnight Attic):**
     - Вайб: Потайной чердак мага, ночной свет свечи, темное дерево, кожа, золото, фиолетовые искры арканы.
   - **Светлая тема (Scholar's Parchment):**
     - Вайб: Старинный манускрипт, стол картографа, пергамент, глубокие чернила, сургучные печати.
   - Тема хранится в `localStorage` под ключом `randomattic_theme`.

## 📌 Памятка по структуре данных генератора

Каждый генератор в `generators-registry.js` описывается объектом следующего вида:
```javascript
{
  id: 'tavern-generator',
  title: 'Генератор Таверн',
  category: 'locations', // 'characters' | 'locations' | 'loot' | 'tools'
  badge: 'Для Мастера',
  description: 'Создание уникальных заведений: меню, выпивка, слухи и колоритные посетители.',
  tags: ['Таверна', 'Слухи', 'Еда', 'Отдых'],
  icon: '🍺',
  status: 'ready', // 'ready' | 'in-progress' | 'planned'
  exampleOutput: '«Хромой Грифон»: Эль из можжевельника (4 мм), жареный вепрь, в углу шепчутся контрабандисты.',
  actionType: 'modal', // 'modal' | 'page' | 'inline'
  actionTarget: 'tavern'
}
```

## 📝 Заметки разработчика по формулам D&D

### Конвертация валют:
- `1 pp` = `10 gp` = `20 ep` = `100 sp` = `1000 cp`
- `1 gp` = `2 ep` = `10 sp` = `100 cp`
- `1 ep` = `5 sp` = `50 cp`
- `1 sp` = `10 cp`
- Базовой единицей расчетов внутри `currency.js` является **медная монета (CP)**.

### Формулы кубиков:
- Бросок с преимуществом (Advantage): бросаем `2d20`, берем большее (`2d20kh1`).
- Бросок с помехой (Disadvantage): бросаем `2d20`, берем меньшее (`2d20kl1`).
- Критический успех на `d20`: выпадение `20`.
- Критический провал на `d20`: выпадение `1`.
